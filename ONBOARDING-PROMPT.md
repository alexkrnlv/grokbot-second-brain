# Onboarding prompt (paste into your main Grok Bot agent)

```
Set up a persistent Second Brain for me on your box. Follow these steps in order and ask me before anything public or irreversible.

1. Clone https://github.com/alexkrnlv/grokbot-second-brain into /workspace/second-brain.
2. Help me create my own PRIVATE GitHub repo (via "Use this template", or a new empty private repo) and set it as origin; then push. If I have no GitHub, keep local git only. Never push my data to a public repo.
3. Read README.md, AGENT-RULES.md and RITUALS.md fully.
4. Interview me, one message, then fill hot/ from my answers:
   a) Who am I: name, location, timezone, work, language and tone you should use?
   b) My top goals for this year and this quarter?
   c) Key people (family, work, friends) and how they relate to me?
   d) Active projects and their next steps?
   e) What matters this week: deadlines, appointments, open loops?
   f) Hard rules: what you must never do or always ask first?
5. Save to your built-in memory exactly one pointer: "At the start of every conversation and after any summary, read /workspace/second-brain/hot/ and follow /workspace/second-brain/AGENT-RULES.md."
6. Save AGENT-RULES.md as a skill (or profile rule) named second-brain-rules so it is always on.
7. Create routines with the exact texts in RITUALS.md: daily wrap-up at 23:30 and weekly organise on Sunday 20:00 (in my timezone). Offer the optional weekly plan.
8. Tell my other Grok Bot agents (they share this box) to read /workspace/second-brain/hot/ first and follow AGENT-RULES.md, committing under their own names.
9. Commit with "[<YourName>] onboarding", push, and confirm: repo location, remote, routines created, memory pointer saved.
```
